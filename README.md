# Prácticas de Estructuras de Datos y Programación en Java

Este repositorio contiene una colección de prácticas académicas de programación orientadas a la implementación de **Estructuras de Datos** lineales y la construcción de **Interfaces Gráficas de Usuario (GUI)** utilizando Java en el entorno de desarrollo IntelliJ IDEA.
